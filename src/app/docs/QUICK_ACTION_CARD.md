## ⚡ Most Common Issues & Instant Fixes

### 1️⃣ Scenario is GREY (Inactive)
```
✅ FIX (10 seconds):
   Click scenario → Click "Activate" → Done!
```

### 2️⃣ "Invalid email in parameter 'to'" Error
```
✅ FIX (2 minutes):
   1. Click Email module
   2. Click in "To" field
   3. Select: 1. Webhooks → email
   4. Save
   📄 Guide: /docs/MAKE_FIX_NOW.md
```

### 3️⃣ Gmail Authentication Expired
```
✅ FIX (1 minute):
   1. Click Email module
   2. Click "Add" next to connection
   3. Re-authenticate Gmail
   4. Save
```

### 4️⃣ No Quotes in 24 Hours
```
✅ CHECK (2 minutes):
   1. Is scenario active? (Green)
   2. Submit test quote from website
   3. Watch execution in Make.com
   4. If webhook doesn't trigger → Check website
```

### 🔴 CRITICAL (Act Now)
- Scenario inactive (grey)
- 3+ consecutive failures
- Webhook not responding

**Action:** Fix within 5 minutes or activate backup

### 🟡 URGENT (Act in 1 Hour)
- 1-2 execution failures
- Email delivery issues
- Slow performance

**Action:** Investigate and fix when possible

### 🟢 MONITOR (Check Daily)
- Single minor error
- Normal operation variations
- Usage tracking

**Action:** Note and monitor trend
